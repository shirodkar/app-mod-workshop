# Application Modernization Workshop

A hands-on workshop that walks you through modernizing a legacy Java EE monolithic application called **Mammoth** using Red Hat technologies on OpenShift.

## Workshop Modules

| Module | Topic | Description |
| ------ | ----- | ----------- |
| [Module 1](modules/module1.md) | Introduction to the Mammoth Application | Explore the legacy Java EE 8 application running on JBoss EAP 7 |
| [Module 2](modules/module2.md) | Upgrading to EAP 8 | Upgrade to Jakarta EE 10 and JBoss EAP 8 using MTA with AI-assisted code changes |
| [Module 3](modules/module3.md) | Rehosting to OpenShift Virtualization | Rehost the application VMs on OpenShift Virtualization |
| [Module 4](modules/module4.md) | Replatforming to OpenShift Containers | Containerize the application using the JBoss EAP 8 Operator |
| [Module 5](modules/module5.md) | Refactoring to Microservices | Refactor the backend to a Quarkus microservice using the Strangler Fig pattern |

## Setup

Workshop setup instructions are available in the [app-mod-gitops](https://github.com/shirodkar/app-mod-gitops) project.

## Getting Started

Begin with [Module 1](modules/module1.md) to explore the Mammoth application and then progress through each module sequentially.
